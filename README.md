# AI & C Exam Simulator

在浏览器里练习 **AI 通识与 C 语言**。选择题、填空题、程序阅读和程序补全共用一个答题界面，提交后显示成绩和错题。

**当前页面对应 `main`。** 此分支配置为 65 题、120 分钟，包含本地成绩历史和错题回顾。

## 本机试用

在当前分支的仓库根目录运行：

```sh
python -m http.server 8765 --bind 127.0.0.1
```

浏览器打开 [http://127.0.0.1:8765/](http://127.0.0.1:8765/)，用示例姓名和学号体验。填完信息进入首页，从首页开始考试。成绩与错题保存在当前浏览器，清理站点数据会清除记录。 按 Ctrl+C 可停止本机服务。

## 两个版本

| | [master](https://github.com/12313Q2312/c-exam-system/tree/master) | [main](https://github.com/12313Q2312/c-exam-system/tree/main) |
|---|---|---|
| 题量与时长 | 60 题 / 90 分钟 | 65 题 / 120 分钟 |
| 计分 | 按题计分 | 程序补全按空计分，其余按题 |
| 结果 | 交卷后查看错题 | 成绩历史和错题可在当前浏览器中查看 |

姓名、学号仅用于前端练习界面。两个版本分别维护。
