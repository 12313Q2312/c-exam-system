# AI & C Exam Simulator

**把 AI 通识与 C 语言题库组织成可在浏览器运行的模拟练习流程。**

项目使用 HTML、CSS 和原生 JavaScript，将资料整理、随机抽题、限时作答、判分与错题展示放在一个静态网页中。网页运行不依赖 npm、后端服务或数据库，适合本地自测与交互原型验证。

> 本文对应 **master 维护线**。仓库默认分支仍为 master，main 有另一套实现和历史 Pages 部署记录；二者的题量、时长和功能不同。

## 两条分支的区别

| 项目 | master | main |
|---|---|---|
| 当前代码配置的时长 | 90 分钟 | 120 分钟 |
| 每次抽题总数 | 60 题 | 65 题 |
| AI / C 单选 / C 填空 / 程序阅读 / 程序补全 | 20 / 15 / 15 / 5 / 5 | 20 / 20 / 15 / 5 / 5 |
| 计分方式 | 现有配置按题计分 | 程序补全按空独立计分，其余按题计分 |
| 成绩历史 | 未见本地历史持久化实现 | 使用浏览器 localStorage |
| 错题 | 交卷结果页展示 | 包含独立错题回顾与本地存储实现 |

表格描述当前源码，浏览器交互与判分正确性仍需验收。分支入口：[master](https://github.com/12313Q2312/c-exam-system/tree/master) · [main](https://github.com/12313Q2312/c-exam-system/tree/main)。维护时分别审查，不直接合并两条历史。

## 三步本地启动

1. 安装 Python 3，打开当前分支的仓库目录。
2. 在仓库根目录运行：

   ```sh
   python -m http.server 8765 --bind 127.0.0.1
   ```

   Windows 若使用 Python Launcher，可以将 `python` 换为 `py -3`。

3. 浏览器打开 [http://127.0.0.1:8765/](http://127.0.0.1:8765/)，按 Ctrl+C 停止服务器。

这个命令只提供本机静态文件访问。原有启动脚本可能使用固定绝对路径、调整防火墙或开放局域网访问，首次运行建议使用上面的最小命令。

## master 的使用与边界

当前代码配置 60 题、90 分钟，包含随机抽题、题型导航、交卷判分和错题展示。

打开页面后填入姓名和学号，点击「查看考试说明」或按 Enter 提交。说明页的「进入考试」按钮才开始抽题与计时。字段为空或只有空格时，页面会提示并聚焦该字段。体验时可使用示例姓名和学号。

考生姓名与学号是前端表单信息，没有服务端身份认证或集中成绩数据库。页面和题库都由浏览器获取，当前实现面向个人练习与原型演示。

## 代码与数据在哪里

| 文件 | 职责 |
|---|---|
| [index.html](index.html) | 页面结构、入口与交互容器 |
| [style.css](style.css) | 页面样式与动画 |
| [app.js](app.js) | 抽题、导航、计时、判分和结果展示 |
| [ai_data.js](ai_data.js)、[c_data.js](c_data.js) | 页面实际加载的题库 |
| [ai_questions.json](ai_questions.json)、[c_questions.json](c_questions.json) | 资料解析得到的 JSON 数据 |
| [extract/parse_pdfs.py](extract/parse_pdfs.py) | 原有 PDF 解析脚本 |
| [ai_full.txt](ai_full.txt)、[c_full.txt](c_full.txt) | 原始提取文本 |
| [验证与整理记录](docs/hygiene-20261103.md) | 检查范围、资产保留与回滚 |

新增或修正题目时，需要明确修改的是页面实际加载的 JS 题库还是中间 JSON，并核对题干、答案、可接受表达与解析之间的一致性。来源 PDF 与提取文本继续保留；解析脚本需要按实际资料检查路径和规则，不应直接覆盖已校对题库。

`.npm-tools/package.json` 与锁文件记录可选 localtunnel 工具的依赖。它们不是静态网页的运行依赖；需要重建该工具时可使用 `npm --prefix .npm-tools ci --ignore-scripts`，本轮未执行联网重装或公网映射。
