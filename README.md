# AI & C Exam Simulator

在浏览器里练习 **AI 通识与 C 语言**。选择题、填空题、程序阅读和程序补全共用一个答题界面，提交后显示成绩和错题。

**这个 README 在默认分支 `master`。** `master` 是 60 题、90 分钟。它不是线上正在部署的版本。

**GitHub Pages 部署的是 `main`，不是 `master`。** 线上站点 [https://12313q2312.github.io/c-exam-system/](https://12313q2312.github.io/c-exam-system/) 从 `main` 分支的根目录发布，对应 65 题、120 分钟。仓库没有单独的测试工作流，Pages 只跑 `pages-build-deployment`。

姓名和学号只用于当前页面，没有账号系统。

## 本机启动

在要试用的那个分支的仓库根目录执行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

浏览器打开 [http://127.0.0.1:8765/](http://127.0.0.1:8765/)。按 Ctrl+C 停止。

要看线上那一版，先切到 `main` 再执行同一条命令。两个分支不要混在同一个工作区里改。

Windows 上也可以双击 `启动服务器.bat`，或运行 `python 启动服务器.py`。这两个启动器绑定 `0.0.0.0:8765`，并尝试添加本机防火墙规则。本机演示用上面的 `127.0.0.1` 命令即可。

## 演示步骤

1. 打开首页，填写姓名和学号。姓名或学号留空时会提示，并停在登录页。
2. 点击「查看考试说明」，确认题量和满分 100 分。
3. 点击「进入考试」。`master` 应显示 `1 / 60`，倒计时从 `90:00` 开始。
4. 点选项或输入答案。用左右箭头、键盘方向键或底部题型标签切换题目。已答题目的圆点会变亮。
5. 点击「交卷」。未答完也可以交，确认框会写出已完成题数；取消则回到原题。
6. 确认后看总分、分题型得分和错题。可以打开「查看排行榜」，这里只显示这一次的成绩。
7. 倒计时走完会自动交卷。页面刷新后回到登录页，这一次的作答不会保留。

## 两个版本

| | `master`（默认分支，本页） | `main`（GitHub Pages 线上） |
|---|---|---|
| 地址 | 需在本地按上面的命令打开 | [线上站点](https://12313q2312.github.io/c-exam-system/) |
| 题量与时长 | 60 题 / 90 分钟 | 65 题 / 120 分钟 |
| 组成 | AI 单选 20×1，C 单选 15×2，C 填空 15×2，阅读 5×2，补全 5×2 | AI 单选 20×1，C 单选 20×1，C 填空 15×1，阅读 5×3，补全 5 题 × 2 空 × 3 |
| 计分 | 按题计分，满分 100 | 补全按空计分，其余按题，满分 100 |
| 结果 | 交卷后在当前页看错题。排行榜只显示本次成绩，不写入浏览器 | 成绩历史和错题保存在当前浏览器，清理站点数据会丢掉 |
| 维护 | 与 `main` 分开 | 与 `master` 分开 |

## 冒烟检查

先按上面的命令启动本机服务，再在仓库根目录运行：

```sh
python3 scripts/smoke_check.py --url http://127.0.0.1:8765/
```

脚本只用 Python 标准库。它会请求页面和题库脚本，核对这一版是 60 题 / 90 分钟还是 65 题 / 120 分钟，并确认题库够抽。不安装新的依赖。
