# 🧠 AI & C语言 考试模拟系统

一个基于 Web 的在线考试模拟系统，涵盖**人工智能通识**和**C语言程序设计**两大科目，支持随机抽题、限时考试、自动判分、成绩排行等功能。

> 📌 在线体验：https://12313q2312.github.io/c-exam-system/

---

## 📖 项目简介

本项目是一个纯前端（HTML + CSS + JavaScript）的考试模拟系统，题目数据来源于两本教材的 PDF 习题集，通过 Python 脚本解析提取后转为 JSON 数据嵌入网页。

考试总分 **100 分**，包含以下题型：

| 题型 | 数量 | 分值 |
|------|------|------|
| 🧠 人工智能通识 选择题 | 20 题 × 1 分 | 20 分 |
| 📝 C语言 单选题 | 20 题 × 1 分 | 20 分 |
| ✍️ C语言 填空题 | 15 题 × 1 分 | 15 分 |
| 🔍 程序阅读题 | 5 题 × 3 分 | 15 分 |
| 🔧 程序补全题 | 5 题 × 2 空 × 3 分 | 30 分 |

---

## ✨ 功能特色

- **登录系统** — 输入姓名和学号后方可进入考试
- **随机抽题** — 每次考试从题库中随机抽取题目，顺序打乱
- **倒计时** — 考试时长 120 分钟，时间到自动交卷
- **翻页答题** — 一题一页，支持键盘 ← → 翻页和触屏滑动
- **题型快捷跳转** — 底部标签页可快速跳转到不同题型
- **即时判卷** — 提交后自动评分，显示各题型得分和总成绩
- **错题回顾** — 展示所有答错题目及其正确答案
- **成绩排行榜** — 本地存储历史成绩，可查看排行榜
- **赛博朋克主题 UI** — 粒子背景动画、霓虹配色、圆环计时器

## 📂 项目结构

| 文件 / 目录 | 说明 |
|-------------|------|
| `index.html` | 主页面（登录 → 首页 → 考试 → 成绩） |

## 🚀 如何运行

### 方法一：直接打开 HTML（最简单）

1. 打开文件夹 `G:\linshicunchuqu\人工智能C语言考试模拟系统`
2. 双击 `index.html`，用浏览器打开即可使用

> ⚠️ 直接打开 HTML 时，`localStorage` 排行榜功能仍然可用，但部分高级功能需要服务器环境。

### 方法二：启动本地服务器（推荐，功能完整）

**方式 A — 双击批处理文件：**

1. 打开文件夹，**双击** `启动服务器.bat`
2. 黑色窗口中会显示一个网址，例如 `http://192.168.x.x:8765`
3. 在浏览器地址栏输入该网址，或输入 `http://localhost:8765`
4. 考试系统就打开了！
5. 用完按 `Ctrl + C` 关闭服务器窗口

**方式 B — 使用 Python 脚本（中文不乱码）：**

1. 在文件夹空白处按住 `Shift` 点击鼠标右键，选择"在此处打开 PowerShell 窗口"
2. 输入以下命令后按回车：
   ```
   python 启动服务器.py
   ```
3. 浏览器访问显示的网址即可

### 方法三：分享给其他人（公网访问）

1. 先双击 `启动服务器.bat` 启动本地服务器
2. 再双击 `启动ngrok.bat`
3. Ngrok 会生成一个公网网址（如 `https://xxxx.ngrok.io`）
4. 把这个网址发给其他人，他们就能访问你的考试系统了

## 📦 从 PDF 提取题库（进阶）

如果你有新的 PDF 习题集，可以用 Python 脚本提取题目：

1. 安装依赖：
   ```
   pip install pdfplumber
   ```
2. 把 PDF 文件放到项目目录下
3. 修改 `parse_pdfs.py` 中的文件名路径
4. 运行脚本：
   ```
   python parse_pdfs.py
   ```
5. 生成的 JSON 数据会保存为 `ai_questions.json` / `c_questions.json`
6. 将它们转换为 `window.AI_QUESTIONS` / `window.C_QUESTIONS` 格式的 JS 文件
